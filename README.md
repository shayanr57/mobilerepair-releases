# Mobile Repair · فایل‌های نصب

این مخزن **فقط برای انتشار فایل‌های نصب** (APK) اپ Mobile Repair است. کد منبع اینجا نیست و منتشر نمی‌شود.

## دریافت
آخرین نسخه را از بخش **[Releases](../../releases/latest)** بگیرید:
- `mobilerepair-play-…apk`: نسخه‌ی معمولی (پیامک را در برنامه‌ی پیامک گوشی باز می‌کند)
- `mobilerepair-direct-…apk`: نسخه‌ای که خودش پیامک می‌فرستد

همان نوعی را بگیرید که روی گوشی نصب است و روی آن نصب کنید. **اپ قبلی را پاک نکنید**؛ با پاک کردن، داده‌های روی گوشی از بین می‌رود.
